# Dectyr RX-5

Home Assistant integration for **Dectyr RX-5** Remote ID detectors: MQTT,
multi-scanner support, drones as dedicated devices, full telemetry, scanner
health, remote commands (reboot, firmware, logs), services and events for
automations, and bundled blueprints.

**Repository:** [github.com/dectyr/ha-integration](https://github.com/dectyr/ha-integration)

**Requirements:** Home Assistant 2024.1 or newer, MQTT integration configured.
Recommended install via HACS (custom repository), then add the **Dectyr RX-5**
integration.
